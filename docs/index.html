03プロジェクトの前提

目的は 2 つあり、どちらも同格に扱う。

  1. カロリー・栄養を記録して可視化する Web アプリとモバイルアプリを完成させる。
  2. 同一の API 仕様を Java と Kotlin の 2 実装で作り、言語差を比較する。

したがって設計上の原則は一貫して、両実装の条件を揃え、言語の差だけが差として残るようにすることである。フレームワーク・DB・ORM・テスト基盤を片方だけ変えてはならない。

この構成の要

「2 実装が同じものである」ことを保証しているのは api/openapi.yaml の 1 ファイルである。API を変更するときは、実装より先にこのファイルを直すこと。Phase 2 では、同じ契約テストを両バックエンドに対して流す仕組みを用意する。
